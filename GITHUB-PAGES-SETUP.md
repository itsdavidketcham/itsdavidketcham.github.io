# Publish this portfolio with GitHub Pages

The site is ready for the existing repository: `itsdavidketcham/itsdavidketcham.github.io`. It is a static site, so no build command or API key is required.

## Upload the files

1. Download `David-Okai-Sarpong-Portfolio.zip` and extract it on your computer.
2. Open the repository at https://github.com/itsdavidketcham/itsdavidketcham.github.io and sign in.
3. Choose **Add file → Upload files**.
4. Upload the *contents* of the extracted `portfolio-site` folder to the repository’s top level. Keep `index.html`, `404.html`, `src`, `assets`, the font files, and `David_Sarpong_CV.pdf` at the same relative paths shown in the package.
5. Commit the uploaded files to the `main` branch.

## Enable or confirm Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then choose **Save**.
4. Wait for the Pages deployment to finish. The site address is https://itsdavidketcham.github.io/.

If Pages already deploys from `main` and the repository root, uploading the files is enough. After publishing, check the page on a phone and desktop, and open `/David_Sarpong_CV.pdf` to confirm the download is public.

## Mobile and other screens

The layout includes responsive breakpoints for navigation, timeline, project cards, galleries, video and the chat panel, plus reduced-motion support. The content reflows to a single column on narrow screens. Check both portrait and landscape on a phone after publishing.
